# apps/web

PWA (React o Vue, **Abierto**) con Service Worker e IndexedDB.

Reglas de diseño: móvil primero, textos cortos, pocas pantallas, botones grandes; mostrar siempre si una acción está pendiente de enviarse.

Pantallas del MVP: entrar · lista de lotes · publicar lote · detalle y oferta · mis pedidos (con estados) · comparador de margen · calificar.

Ver `docs/02-funcionalidades-mvp.md`.
